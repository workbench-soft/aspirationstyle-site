# aspirationstyle-site

The built pages of `aspirationstyle.ru`, served by GitHub Pages. Don't edit
them here.

- **Source** the private
  [`workbench-soft/aspirationstyle`](https://github.com/workbench-soft/aspirationstyle)
  holds the Astro site, the admin and the docs.
- **Deploy** the Release workflow of `aspirationstyle` builds the site and
  pushes it here once Checks pass. Each deploy replaces every file except this
  README.
- **Why two repos** the org is on the free plan, and GitHub Pages serves a free
  org only from a public repo. The source stays private.
